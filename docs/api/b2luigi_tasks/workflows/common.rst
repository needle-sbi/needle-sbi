Common Utilities
================

Programmatic configuration of the b2luigi runtime (batch system, result directory,
environment script) — the equivalent of a ``settings.json`` file. Supported batch systems:
``"local"``, ``"htcondor"``, ``"slurm"``, ``"lsf"`` (law only supports htcondor and slurm).
